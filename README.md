# .github

Organization-wide defaults for **APPCO PTE. LTD.** on GitHub. The `profile/README.md` in this
repository is the public organization page shown at
[github.com/APPCO-PTE-LTD](https://github.com/APPCO-PTE-LTD),
and everything else here — issue templates, the pull request template, `SECURITY.md`, and
`CODE_OF_CONDUCT.md` — is inherited automatically by any repository in the organization that does
not define its own. Change a template once here instead of copying it into every repository.
Anything meant only for organization members lives in the private `.github-private` repository
instead, since this one is public.
