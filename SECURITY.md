# Security policy

This policy covers every repository in the **APPCO-PTE-LTD** organization that does not define its
own.

## Reporting a vulnerability

**Do not report security vulnerabilities through public issues, discussions, or pull requests.**

Report privately, either way:

- **Private security advisory:** on the affected repository, open the **Security** tab and choose
  **Report a vulnerability**.
- **Email:** <!-- add the security contact address -->

Include as much as you can:

- the affected repository, URL, or app, and its version
- steps to reproduce, or a proof of concept
- the impact: what data or action it exposes

## What to expect

- Every security report is treated as at least **high priority** and handled in private.
- We aim to acknowledge your report the same working day.
- We keep you updated through to resolution and tell you when the fix is deployed.

## Supported versions

Only the latest release of each product, the version running in production, is supported.
Fixes ship as a new release. Older releases are not patched.

## Disclosure

Please keep the details private until we confirm the fix is deployed. We disclose publicly only
after that.
